Three differentiators:
  1. Offline-first — add expenses on a trek, sync later
  2. Mobile speed — optimistic UI, no spinners on common actions
  3. SEO-first — landing/features/use-case pages SSG with full JSON-LD; standalone calculators as ranking bait

Phase 1 — Core MVP

Target: 5–7 weeks · Progress PWA + calculator + tests + legal pages

A. Auth + profile

  • Google OAuth (one-click)
  • Email magic-link (fallback)
  • User profile (display name, avatar)
  • Sign-out + delete-account

B. Groups

  • Create group: name, primary currency picker
  • Join via shareable 32-byte link
  • Group settings (rename, currency, leave, kick)
  • Members list

C. Expenses (multi-currency day 1)

  • Add expense: payer, amount, currency, date, who-shares
  • FX conversion at entry (free FX API)
  • Split types: equal · exact · share · percent
  • Edit / delete expense
  • Comments per expense
  • Activity feed

D. Balances

  • Per-person balance in primary currency
  • Group summary (you owe / are owed)
  • Simplify Payments toggle (greedy algo)
  • Settle-up flow

E. Offline (the wedge)

  • PWA manifest + install prompt
  • Service Worker caches app shell
  • IndexedDB via Dexie stores data
  • Event queue for offline mutations
  • Background Sync API on reconnect
  • Conflict resolution (last-write-wins)

F. Marketing site + SEO

  • Landing (/) with hero + features + CTA
  • /features long-form
  • /use-cases/* hub: rent, trip, roommate, dinner, family
  • /calculators/split-bill public tool (SEO bait)
  • /about, /privacy, /terms
  • Full JSON-LD on all marketing pages
  • sitemap.xml + robots.txt + OG cards
  • Lighthouse 95+ on marketing
  • Vercel Analytics + Speed Insights

G. Ads (monetization)

  • AdSense application (apply early)
  • Banner on group dashboard (lazy)
  • Native cards in activity feed
  • Hard rule: zero ads on add-expense / settle-up / login

H. Polish

  • Mobile-first responsive (375 → 1280px)
  • Dark mode (auto + manual)
  • Empty / error states
  • Toasts + skeleton loaders only where needed
  • OG cards + favicon + manifest

I. Launch checks

  • Lighthouse 95+ mobile
  • PWA install on Android + iOS
  • Offline test: airplane → add → reconnect → sync
  • Privacy + terms drafted
  • Custom domain + GSC verification + sitemap submission

Phase 2 — UX wins

  • Receipt photo upload (Supabase Storage)
  • Categories (Food, Travel, Stay, Misc, custom)
  • Recurring expenses (rent, subs)
  • Bulk-split: one bill across line items
  • Export to CSV / PDF
  • Trip mode: daily summary, per-day spend
  • Historical FX rates (lock per-expense rate at entry)
  • View balances in any currency

Phase 3 — Power features

  • OCR receipt scanning (Google Cloud Vision free tier)
  • AI categorization (Claude Haiku)
  • WhatsApp bot (Meta Cloud API, DM only)
  • Voice input
  • Reminder nudges (configurable)
  • SMS UPI debit parsing

Phase 4 — Optional Pro tier

  • Revisit freemium if ad CPMs are too low or AdSense rejected
  • Pro tier ₹99/yr — no ads, OCR, recurring, exports, WhatsApp
  • Razorpay/Stripe integration
